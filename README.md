# Aegis Scanner 

An entry-level Python project that involves scanning networks and performing basic vulnerability analysis using Nmap.

##  Features
- Scans for open ports and services on target systems  
- Assigns basic CVSS scores to indicate risk levels  
- Generates reports in PDF format  
- Visualizes data using simple charts (matplotlib)  

##  Tools & Technologies
- Python  
- Nmap  
- Matplotlib  

##  Description
This project is part of my cybersecurity learning. I developed a tool that scans a network using Nmap to identify open ports and running services. Based on the results, it performs a basic vulnerability assessment.

It also generates simple reports and visualizes the collected data using charts. This project helped me understand how network scanning and risk analysis work in real-world scenarios.

##  Output
- Open ports and services list  
- Basic vulnerability report  
- CVSS-based risk scoring  

##  Learning Outcome
- Understanding of Nmap-based network scanning  
- Basics of vulnerability assessment and CVSS scoring  
- Hands-on experience with Python in cybersecurity
